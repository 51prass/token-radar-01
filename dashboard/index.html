How the model works

Every implied value on this board comes from the snapshot's own figures. No protocol name is ever special-cased: the same formula scores every row.

implied value = TVL × size × category × growth × maturity × breadth

  • size — the TVL multiple, 0.32 at $50M of TVL sliding to 0.18 at $2B, log-interpolated. A bigger protocol is worth more in dollars, but each extra TVL dollar buys less of it.
  • category — what the protocol does sets its revenue quality: exchanges and lending desks 1.10–1.15, bridges and wrappers 0.72–0.85, the rest in between.
  • growth — 1 + the 7-day TVL change (clamped to −60%…+150%) × 0.7. Momentum lifts a protocol; shrinkage warns. A missing reading counts as flat.
  • maturity — 0.7 + 0.3 × √(age ÷ 4 years). A protocol that has run for years with no token is a longer-standing launch candidate, with the curve flattening over time. Unknown age counts as one year.
  • breadth — 1 + 0.04 per extra chain, up to five. A protocol live on several chains reaches more farmers.

A protocol on this board records no token in DefiLlama's data. That is not proof it has none: a token may exist that the record does not carry. Implied values are this radar's own claim, never a promise that a token will be issued or what it would trade at.
